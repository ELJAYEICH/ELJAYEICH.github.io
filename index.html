Auto Shorts Uploader

Auto Shorts Uploader is a personal automation project that helps its owner create short-form videos using AI-generated scripts, stock footage, narration, and captions.

How It Works

The application generates video scripts, collects stock footage, creates narration and subtitles, and assembles the resulting video. After the owner authorizes access, the application can upload videos to the owner's YouTube channel.

Google and YouTube Data

The application uses Google OAuth authorization to upload videos to the connected YouTube channel. It uses the permissions granted by the account owner for this purpose.

OAuth credentials are stored as GitHub Actions repository secrets and are not included in this public website.
