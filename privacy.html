Privacy Policy

Effective date: October 13, 2026

1. About This Application

Auto Shorts Uploader is a personal automation project used by its owner to create and upload YouTube Shorts.

2. Information Accessed

With the owner's authorization, the application uses Google OAuth credentials to upload videos to the owner's YouTube channel. It accesses only the permissions needed for the authorized upload workflow.

3. How Information Is Used

Google authorization is used to upload the generated video, title, description, tags, and publication settings to YouTube. The application does not sell Google user data or use it for advertising.

4. Storage and Security

OAuth credentials are stored as encrypted GitHub Actions repository secrets and are provided to the automation workflow when required. Credentials should never be included in source code or public logs.

Generated scripts, video files, and other workflow outputs may be retained temporarily as GitHub Actions artifacts, subject to the repository's artifact retention settings.

5. Sharing

The application uses Google services to authorize and upload videos, GitHub Actions to run the workflow, Gemini API to generate scripts and narration, and Pixabay to search for stock footage. Information is transmitted to these services only as needed for the described functions.

6. Data Retention and Revocation

The owner can remove stored workflow artifacts and revoke the application's Google authorization through their Google Account security settings. Revoking access may stop automated uploads.
