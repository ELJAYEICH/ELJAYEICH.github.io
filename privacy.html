Privacy Policy

Effective date: October 13, 2026

1. About This Application

Auto Shorts Uploader is a personal automation project used by its owner to create and upload YouTube Shorts.

2. Information Accessed

With the owner's authorization, the application uses Google OAuth credentials to upload videos to the owner's YouTube channel.

3. How Information Is Used

Google authorization is used to upload generated videos, titles, descriptions, tags, and publication settings to YouTube. Google user data is not sold or used for advertising.

4. Storage and Security

OAuth credentials are stored as GitHub Actions repository secrets and supplied to the automation workflow when needed. Credentials must not be included in source code or public logs.

Generated scripts, videos, audio, and other workflow outputs may be stored temporarily as GitHub Actions artifacts. Retention depends on the workflow settings.

5. Third-Party Services

The application uses Google services for authorization and YouTube uploads, Gemini API for script and narration generation, GitHub Actions for workflow execution, and Pixabay for stock video searches.

Information is sent to these services as necessary to provide the application's functions and is subject to the relevant service policies.

6. Data Deletion and Access Revocation

To request deletion of application data under the owner's control, contact the email address below. Requests will be reviewed and handled where technically possible. Data held by third-party services may need to be deleted through those services separately.

The owner can revoke Google account access through Google Account security settings. Revoking access prevents further authorized uploads until access is restored.
